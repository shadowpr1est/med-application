# SmartMed — чеклист до полноценного приложения

План исходит из текущего проекта: адаптивное локальное PWA-приложение без аккаунта и backend. Целевая схема: **PWA frontend на Netlify + Firebase для аккаунтов/данных/фото + Firebase Cloud Functions и Cloud Tasks для серверной логики и отложенных задач**. Netlify остаётся хостингом пользовательского интерфейса; задача конкретного приёма должна выполняться сервером независимо от открытой вкладки.

- [ ] Не считать отсутствие фото или уведомления доказательством того, что лекарство пропущено.

**Важно для Netlify:** статические файлы PWA можно публиковать на Netlify, а функции Netlify подходят для API и некоторых фоновых задач. У Scheduled Functions есть ограничения среды, в том числе лимит выполнения 30 секунд, и они работают только в опубликованном deploy. Для точного индивидуального времени каждого приёма используйте очередь задач backend, а не один общий опрос расписания с frontend. См. [Netlify Scheduled Functions](https://docs.netlify.com/build/functions/scheduled-functions/) и [Firebase Cloud Tasks](https://firebase.google.com/docs/functions/task-functions?hl=en).
